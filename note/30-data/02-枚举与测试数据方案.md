# 枚举与测试数据方案

状态：初稿

## 外网测试假设

- 预警阈值：10%
- 推送对象：全部测试用户
- 审批：不接 BPM，先用草稿/已提交/已通过/已退回模拟
- 真实主数据：外网使用模拟数据
- 单位字典：外网按业务截图模拟核算单位、管理单位、往来单位、是否集团内、是否八院内
- 业务方源表：外网按业务方建表参考模拟源项目树、工作令关联字典和账面成本凭证明细

## 枚举草案

| 枚举 | 值 |
|---|---|
| 项目状态 | 草稿、已提交、已通过、已退回 |
| 填报状态 | 未填报、部分填报、已填报 |
| 预警等级 | 正常、超支 |
| 阶段 | M、C、S、D、Z【需确认】 |
| 项目获取方式 | 竞争择优、单一来源、其他【需确认】 |
| 单位分类 | 院内、院外；当前按 `cost_unit_dict.inside_institute` 判断 |
| 源数据导入类型 | `SOURCE_PROJECT_TREE`、`WORK_ORDER_REF`、`LEDGER_DETAIL` |

## 测试数据规模

| 数据 | 建议规模 |
|---|---|
| 领域 | 4 个 |
| 每个领域系列 | 2-3 个 |
| 每个系列型号/项目 | 3-5 个 |
| 每个项目基本情况 | 2-5 条 |
| 每个项目工作令基础信息 | 3-10 条 |
| 单位字典 | 20 条左右 |
| 源主业项目树 | 至少覆盖当前主业项目 |
| 工作令关联主业项目字典 | 至少覆盖重点演示项目工作令 |
| 账面成本凭证明细 | 至少覆盖多个科目、阶段、借贷方向 |
| 院外成本明细 | 每个重点演示项目 2-5 条 |
| 超支样本 | 至少 5 个 |

源数据样例覆盖：

- `cost_work_order_project_ref`：覆盖 `ZY-2026-LA-001` 的主要院内工作令，并补充导弹、卫星样例。

预警记录包含 4 条工作令超支/推送相关样本、1 条低于 10% 阈值的正常样本、1 条项目级正常样本，用于筛选测试。
