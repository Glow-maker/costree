# PRD - 成本库第一阶段 MVP

状态：初稿

## MVP 目标

让成本库数据可进入、可维护、可查询、可控权限。

## 命名口径

- `Table 2`、`Table 3` 只保留为原型阶段追溯编号，不作为最终菜单、页面、接口、权限和数据库命名。
- `Table 2` 在开发文档中统一落为“项目基本情况”，主要开放给项目办维护。
- `Table 3` 在开发文档中统一落为“工作令基础信息”，主要开放给研制单位维护。
- 最终页面按角色拆分，不做一个长期混合页面：项目办进入“项目基本情况维护”，研制单位进入“工作令基础信息维护”。

## 功能范围

| 功能 | 是否 MVP | 说明 |
|---|---|---|
| 菜单接入 | 是 | 嵌入现有数据中台 |
| 成本项目列表 | 是 | 查询、分页、进入详情 |
| 项目详情/锚定信息 | 是 | 展示主业项目基础信息，作为两类维护页共同上下文 |
| 项目基本情况 CRUD | 是 | 原型 `Table 2`，项目办维护 |
| 工作令基础信息 CRUD | 是 | 原型 `Table 3`，研制单位维护 |
| 保存草稿/提交状态 | 是 | 不接正式 BPM，先做状态流转【需确认】 |
| Excel 导入 | 是 | 优先支持项目基本情况或工作令基础信息中的一个模板【需确认优先级】 |
| 导出 | 是 | 按当前角色页面导出列表或明细 |
| 权限控制 | 是 | 菜单、按钮、基础数据权限 |
| 预警 | 简版 | 阈值暂定 10%，全部推送【外网测试假设】 |
| 驾驶舱 | 后置 | 二阶段 |
| 型号对比 | 后置 | 二阶段 |
| 成本树详情 | 后置 | 二阶段 |

## 验收口径

- 外网 MySQL 测试数据可支撑完整演示。
- 成本项目列表、项目锚定信息、项目基本情况、工作令基础信息可完成查询和维护。
- 模板导入和导出可运行。
- 项目办不能进入或操作研制单位专属维护入口；研制单位不能进入或操作项目办专属维护入口【需确认是否允许只读】。
- 权限点可控制菜单、按钮显示和接口访问。
