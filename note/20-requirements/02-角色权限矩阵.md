# 角色权限矩阵

状态：初稿

## 角色草案

| 角色 | 说明 | 数据范围 |
|---|---|---|
| 成本库管理员 | 管理全部测试数据 | 全部 |
| 项目办 | 维护项目基本情况，原型对应 `Table 2` | 授权项目 |
| 研制单位 | 维护工作令基础信息，原型对应 `Table 3` | 本单位或授权项目【需确认】 |
| 审核人员 | 查看并提交状态意见 | 授权项目 |
| 管理层 | 查看统计和预警 | 全部或授权范围【需确认】 |

## 页面开放草案

| 页面/入口 | 成本库管理员 | 项目办 | 研制单位 | 审核人员 | 管理层 |
|---|---|---|---|---|---|
| 成本项目列表 | 可查/可维护 | 可查授权项目 | 可查授权项目 | 可查授权项目 | 可查 |
| 项目锚定信息 | 可查 | 可查 | 可查 | 可查 | 可查 |
| 项目基本情况维护 | 可维护 | 可维护 | 默认不可操作【需确认是否只读】 | 可查/审核【需确认】 | 可查 |
| 工作令基础信息维护 | 可维护 | 默认不可操作【需确认是否只读】 | 可维护 | 可查/审核【需确认】 | 可查 |
| Excel 导入导出 | 可操作 | 仅项目基本情况 | 仅工作令基础信息 | 默认不可操作【需确认】 | 默认不可操作 |
| 预警记录 | 可查/可推送 | 可查授权项目【需确认】 | 可查本单位【需确认】 | 可查【需确认】 | 可查 |

## 权限点草案

| 权限点 | 用途 |
|---|---|
| `cost:project:query` | 查询成本项目 |
| `cost:project:create` | 新增成本项目 |
| `cost:project:update` | 编辑成本项目 |
| `cost:project:delete` | 删除成本项目 |
| `cost:project:import` | 导入 |
| `cost:project:export` | 导出 |
| `cost:project-basic:query` | 查询项目基本情况 |
| `cost:project-basic:create` | 新增项目基本情况 |
| `cost:project-basic:update` | 编辑项目基本情况 |
| `cost:project-basic:delete` | 删除项目基本情况 |
| `cost:project-basic:import` | 导入项目基本情况 |
| `cost:project-basic:export` | 导出项目基本情况 |
| `cost:work-order:query` | 查询工作令基础信息 |
| `cost:work-order:create` | 新增工作令基础信息 |
| `cost:work-order:update` | 编辑工作令基础信息 |
| `cost:work-order:delete` | 删除工作令基础信息 |
| `cost:work-order:import` | 导入工作令基础信息 |
| `cost:work-order:export` | 导出工作令基础信息 |
| `cost:project:submit` | 保存后提交状态流转 |
| `cost:warning:query` | 查看预警 |
| `cost:warning:push` | 推送预警 |
