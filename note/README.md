# 成本库嵌入数据中台文档中心

本目录用于长期维护成本库 MVP 从调研、需求、数据、接口、前端、后端、测试到迁移上线的全部实施文档。

## 当前阶段

- 阶段：第一阶段 MVP 实现、原型迁移和权限链路收口进行中
- 目标：让成本库数据可进入、可维护、可查询、可控权限，并逐步迁移总体展示、目录树、项目详情、成本树详情、数据采集前台页和统计分析页
- 技术取舍：React/Figma 原型只作为页面与交互参考，最终按数据中台 Vue3 + Java/Spring Boot/Yudao 规范重写
- 测试策略：先用外网 MySQL 构造测试数据跑通，再迁移到内网真实数据环境
- 当前跟进：成本库本地代理默认跟随业务中台真实登录态；本轮已用 `VITE_BASE_URL=http://127.0.0.1:38080` 复核 `/cost/pending-allocation`、`/cost/warning`、`/cost/catalog`
- 最新页面：新增 `/cost/pending-allocation` 待分配池，用于展示产品简称未填或填写 `待分配` 的工作令及单位穿透
- 学习协作：后续按“边写代码边解释链路”的方式推进，见 `00-overview/02-全栈边做边学与运行链路说明.md`
- 自主开发：已建立成本树代码阅读地图，见 `00-overview/03-成本树代码阅读地图与自学路线.md`
- 工程约束：开发前先查 `00-overview/04-工程经验与开发约束手册.md`，避免重复踩分页、聚合、权限、导出和需求拆解类问题
- 长期维护：本项目按“文档作为项目操作系统”持续维护，开工、开发、收尾和周巡检机制见 `00-overview/05-长期项目文档与工程经验沉淀模式.md`
- 对话接管：开启新 Codex/ChatGPT 对话前，先按 `00-overview/06-新对话接管成本库项目启动指南.md` 提供入口文件和启动 prompt

## 代码仓库位置

本文档默认从 `<costree-root>` 表示当前 `costree` 文档仓库根目录。若按当前推荐布局放置仓库，前端和后端相对路径分别为 `../sqlbot_with_bcback/costree-frontend`、`../sqlbot_with_bcback/baback`；如果内网机器目录不同，只需要把 `<frontend-root>`、`<backend-root>` 替换为实际仓库根目录，不要在文档中写死本机盘符。

| 类型 | 路径 | 说明 |
|---|---|---|
| 成本库前端开发仓库 | `<frontend-root>`，推荐相对路径 `../sqlbot_with_bcback/costree-frontend` | Vue3 中台前端，当前分支 `costree`，跟踪 `codeup/feature/costree2` |
| 数据中台后端 | `<backend-root>`，推荐相对路径 `../sqlbot_with_bcback/baback` | Yudao Java/Spring Boot 后端，当前分支 `feature/costree`，跟踪 `codeup/feature/costree` |
| 文档和 React/Figma 原型 | `<costree-root>` | `note` 和 `.agent-handoff` 所在位置；原型只作为页面、字段和交互参考 |

## 维护规则

- 不确定事项统一标记为【需确认】。
- 每个文档只承担一个职责，不把 PRD、SQL、接口和页面实现说明混在一起。
- 账号、密码、Token 等敏感信息只集中维护在 `80-deployment/00-环境账号与敏感信息.md`。
- 先改设计文档，再生成代码或 SQL。
- 新增需求、接口、页面、聚合或导出前，先查 `00-overview/04-工程经验与开发约束手册.md`。
- 周期超过一周、涉及多轮需求或多人/AI 协作的新项目，建议按 `00-overview/05-长期项目文档与工程经验沉淀模式.md` 初始化文档中心。
- 每轮重要开发结束后，至少更新 `PROJECT_STATE.md`、`PLAN.md`、`90-logs/02-变更日志.md`；出现风险、关键取舍或踩坑时，同步更新 `RISKS.md`、`DECISIONS.md` 和工程经验手册。
- 新对话接管成本库项目前，先复制 `00-overview/06-新对话接管成本库项目启动指南.md` 中的启动 prompt。
- 每次关键取舍写入 `90-logs/01-决策记录.md`。
- 每次阶段性变更写入 `90-logs/02-变更日志.md`。
