### B6-0 HTTP 联调阻塞结论

- 成本库业务接口的实际访问路径需要带中台管理端前缀：`/admin-api/cost/...`。
- 直接访问 `/cost/...` 会出现路径不匹配或绕过中台前缀的问题，不作为前端联调路径。
- 不带登录态访问 `/admin-api/cost/project-basic/get-import-template` 时，平台安全链路返回未登录。
- 使用 `Authorization: Bearer test1` 时，`TokenAuthenticationFilter` 会先调用 `system-server` 的 `OAuth2TokenApi#checkAccessToken`；当前外网测试环境未启动/注册 `system-server`，因此返回 503。
- 使用 `login-user` 请求头可以绕过 token 校验，但多租户过滤器仍会调用 `system-server` 的 `TenantApi#validTenant(Long)`；当前同样因缺少 `system-server` 阻塞。
- 发生上述异常时，框架错误日志还会尝试调用 `infra-server` 的 `ApiErrorLogApi#createApiErrorLog`；当前缺少 `infra-server` 会产生二次错误日志。
- 结论：当前阻塞是平台依赖缺失，不是导入模板或导入接口业务代码已被证实失败。
- 本地外网测试阶段允许新增默认关闭的 `cost.local-test.mock-platform` 开关，仅用于 `cost-server` 单服务 HTTP 验证；内网部署和中台集成时必须关闭，继续复用真实登录、租户、权限、错误日志能力。
