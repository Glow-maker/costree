## 单位树复核修正（本轮用户反馈）

账面穿透弹窗修复：AppView/FullView 原先使用 route.fullPath 作为页面 key，成本项参数变化会重建整个页面；初始化/路由恢复还会同步清除 itemCode，造成闪屏及弹窗状态竞争。现在仅账面穿透页使用稳定 path key，其他页面不变；读取路由时先完成数据恢复，不反向清除成本项。新增 3 项回归测试通过，成本类型检查通过。本地逐项点击八个成本项和全部借方均保持弹窗；事务费 1 条 610 万元、折旧费 1 条 620 万元，零金额项显示 0 条。

最新修正：恢复纵向/横向工作令左右并列，移除上下堆叠及横向分组绕至最左边的长连线。每组内部最多四列、滚动、折叠及成本穿透保留。实测电子所纵向 2 条、横向 1 条在 100% 和 70% 下并排且连接正常；类型检查通过。[70% 修复截图](unit-groups-restored-70.png)。本段覆盖上一轮的上下分组布局。

上一版将树容器改成 overflow: visible，导致受父容器裁剪的工作令没有可用滚动条；右侧卡片参与居中布局挤偏了单位节点，同时关闭原 CSS 连线造成断裂。现恢复受视口限制的双向滚动区域，成本卡片独立定位于单位右侧，并使用按实际节点位置绘制的 SVG 连线，适应换行和折叠。

成本卡片改为项目页同款“账面成本组成”：标题和两位小数金额、小尺寸环图、相同八色及底部查看提示。点击可查看八项金额，汇总数据口径不变。

补充穿透：点击环图扇区或弹窗成本项进入账面成本详情；“查看全部明细”进入单位完整范围。携带项目、管理单位/核算单位、阶段、成本项及返回单位页信息。实测材料费下钻保留电子所和项目范围，自动打开材料费明细（1 条、80 万元），单位总账面仍为 1,000 万元。类型检查通过。

实际打开 ZY-2026-DEMO-YEAR-002 电子所验证：右侧显示 1,000.00，八项为 120/80/140/110/90/110/150/200；滚动到底部可查看并展开工作令。单位折叠后 SVG 路径从 3 条变为 1 条，展开恢复。

修正截图：[顶部卡片与滚动条](unit-scroll-fixed-top.png)、[滚动后的工作令](unit-scroll-fixed-bottom.png)。这些修正取代下文上一轮关于树容器无界滚动和独立大饼图的表现。

本轮没有提交、推送、重新制作离线包、重启后端或修改真实数据库。前端来自正在运行的开发服务；后端修改经过编译和测试，但当前旧进程尚未加载。本次沿用现有表字段，无新增业务表、无须执行字典 DDL。
