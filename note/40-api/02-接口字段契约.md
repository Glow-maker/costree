# 接口字段契约

状态：初稿

## 1. 目标

定义成本库 MVP 接口的请求参数、响应字段、字段类型、必填规则和错误场景。后续生成前端 `src/api/cost/...`、后端 Controller、ReqVO、RespVO、ExcelVO 时，以本文件为字段口径。

## 2. 通用约定

| 项 | 约定 |
|---|---|
| 数据库字段 | 使用 `snake_case`，以 `schema-mvp.sql` 为准 |
| 接口字段 | 使用 `camelCase`，便于 Vue3/TypeScript 使用 |
| 金额字段 | `BigDecimal` / `number`，单位暂定“万元”【需确认】 |
| 日期时间字段 | `LocalDateTime` / `string`，格式 `YYYY-MM-DD HH:mm:ss` |
| 研制周期字段 | `string`，格式 `YYYY-MM` |
| 分页响应 | 复用 Yudao `PageResult<T>`：`list`、`total` |
| 通用响应 | 复用 Yudao `CommonResult<T>`：`code`、`data`、`msg` |
| 删除 | MVP 走逻辑删除，表字段 `deleted` |
| 租户 | 表保留 `tenant_id`，外网测试统一使用 `124`，与本地代理 `VITE_COST_LOCAL_TENANT_ID` 保持一致 |

### 10.1 `GET /cost/warning/page`

- 若操作时 `cost_warning_record` 尚不存在，后端会基于当前工作令实时计算结果创建一条状态记录。
- 后续接入中台消息中心后，`resend` 应改为调用真实消息推送，并回填 `messageId`、失败原因和接收人范围【需确认】。
- 后续正式整改闭环如需要经办人、处理说明、附件或审批记录，应新增处理记录表，不建议继续塞进 `remark`【需确认】。

## 11. 校验和错误场景

### 11.1 数据采集轻流程接口

项目基本情况：

| 接口 | 说明 | 权限点 |
|---|---|---|
| `POST /cost/project-basic/submit?id=` | 提交项目基本情况 | 当前复用 `cost:project-basic:update`【需确认】 |
| `POST /cost/project-basic/approve?id=` | 确认通过项目基本情况 | 当前复用 `cost:project-basic:update`【需确认】 |
| `POST /cost/project-basic/reject?id=` | 退回项目基本情况 | 当前复用 `cost:project-basic:update`【需确认】 |

工作令基础信息：

| 接口 | 说明 | 权限点 |
|---|---|---|
| `POST /cost/work-order/submit?id=` | 提交工作令基础信息 | 当前复用 `cost:work-order:update`【需确认】 |
| `POST /cost/work-order/approve?id=` | 确认通过工作令基础信息 | 当前复用 `cost:work-order:update`【需确认】 |
| `POST /cost/work-order/reject?id=` | 退回工作令基础信息 | 当前复用 `cost:work-order:update`【需确认】 |

状态流转：

| 当前状态 | 可执行动作 | 目标状态 |
|---|---|---|
| `DRAFT` | 提交 | `SUBMITTED` |
| `REJECTED` | 重新提交 | `SUBMITTED` |
| `SUBMITTED` | 确认通过 | `APPROVED` |
| `SUBMITTED` | 退回 | `REJECTED` |
| `APPROVED` | 第一版不允许编辑或重新提交 | - |

说明：

- 本轮不接正式 BPM 流程实例，只使用业务表 `status` 字段完成轻流程闭环。
- 第一版没有新增 `submitTime`、`approveTime`、`rejectReason`、`revisionNo` 字段；后续内网真实流程需要补齐【需确认】。
- 正式展示页后续建议统一只读取 `APPROVED` 数据；当前前端演示页尚未强制切换该口径，避免外网测试数据减少。

| 场景 | 建议处理 |
|---|---|
| `projectId` 不存在 | 返回业务错误：主业项目不存在 |
| 工作令编号重复 | 返回业务错误：工作令编号已存在 |
| 金额字段小于 0 | 返回参数错误 |
| `cycleEnd` 早于 `cycleStart` | 返回参数错误 |
| `quantity` 小于等于 0 | 返回参数错误 |
| `stageCode` / `stageCodes` 不在枚举内 | 返回参数错误【需确认字典来源】 |
| 无按钮/接口权限 | 由 `@PreAuthorize` 拦截 |
| 数据权限不匹配 | 查询不到数据或返回无权限【需确认中台规则】 |
| 导入文件为空或格式错误 | 返回导入失败和错误明细 |
| 同步导出超过 5000 行 | 返回业务错误：导出数据超过 5000 行，请缩小筛选范围后重试 |
| 预警重复推送 | MVP 允许重复推送还是拦截【需确认】 |
| 状态流转不合法 | 返回业务错误：当前状态不允许执行该操作 |

## 12. 待确认事项

- 阶段多选在接口中使用逗号字符串还是数组。当前数据库存逗号字符串，前端可按数组展示。
- 项目状态是项目级统一提交，还是项目基本情况/工作令分别提交。
- 项目办是否允许只读查看工作令基础信息；研制单位是否允许只读查看项目基本情况。
- 预警列表是否需要冗余 `projectCode`、`projectName`、`workOrderNo` 到 `cost_warning_record`，避免分页联表。
- Excel 导入模板字段是否与保存接口完全一致，还是存在导入专用字段。
- `cost_unit_cost_detail` 后续是否需要支持版本、月份或导入批次，避免同一项目/阶段/单位只有一份明细。
