# 接口联调用例

状态：初稿

## 1. 目标

记录外网测试阶段的接口调用顺序、示例参数和预期返回，方便后续生成 Postman / Apifox 用例，也方便前端页面逐步联调。

本文件只记录接口用例，不记录数据库账号密码。数据库连接信息见 `80-deployment/00-环境账号与敏感信息.md`。

## 2. 前置条件

- 外网 MySQL `costree_mvp` 已执行 `30-data/schema-mvp.sql`。
- 外网 MySQL `costree_mvp` 已执行 `30-data/seed-mvp.sql`。
- 当前测试数据包含：
  - 主业项目 `1001`：`ZY-2026-LA-001`，有项目基本情况、工作令和预警样本。
  - 主业项目 `1003`：`ZY-2026-DW-001`，有多阶段工作令和超支样本。
  - 主业项目 `1005`：`ZY-2026-ST-001`，有已审批项目基本情况和工作令样本。
  - 主业项目 `1007`：`ZY-2026-SP-001`，有推送成功、失败、未推送预警样本。

## 3. 推荐联调顺序

| 顺序 | 用例 | 目标 |
|---|---|---|
| 1 | 查询型号树 | 验证菜单筛选基础数据 |
| 2 | 查询成本项目列表 | 验证项目入口页 |
| 3 | 查询项目锚定信息 | 验证项目办/研制单位页面左侧只读信息 |
| 4 | 查询项目基本情况 | 验证项目办维护页 |
| 5 | 查询工作令基础信息 | 验证研制单位维护页 |
| 6 | 查询预警记录 | 验证 10% 超支样本 |
| 7 | 新增/编辑/删除项目基本情况 | 验证 CRUD |
| 8 | 新增/编辑/删除工作令基础信息 | 验证 CRUD 和工作令编号唯一性 |
| 9 | 下载模板/导入/导出 | 验证 Excel 链路 |
| 10 | 推送预警 | 验证外网全部推送测试链路 |

## 4. 只读查询用例

### 4.1 查询型号树

接口：

`GET /cost/model-node/tree`

请求参数：

| 字段 | 示例 |
|---|---|
| `status` | `ENABLE` |

预期：

- 返回 4 个一级领域：运载火箭、导弹武器、卫星项目、空间安全。
- 每个领域下有系列和型号节点。

### 4.2 查询成本项目列表

接口：

`GET /cost/project/page`

请求参数：

| 字段 | 示例 |
|---|---|
| `pageNo` | `1` |
| `pageSize` | `10` |
| `domainCode` | `LAUNCH` |

预期：

- 返回运载火箭领域的项目。
- 种子数据中应包含 `ZY-2026-LA-001` 和 `ZY-2026-LA-002`。

### 4.3 查询项目锚定信息

接口：

`GET /cost/project/get?id=1001`

预期关键字段：

| 字段 | 预期 |
|---|---|
| `projectCode` | `ZY-2026-LA-001` |
| `projectName` | `CZ-8A 批产改进主业项目` |
| `domainName` | `运载火箭` |
| `projectOfficeStatus` | `FILLED` |
| `unitFillStatus` | `FILLED` |
| `auditStatus` | `SUBMITTED` |

### 4.4 查询项目基本情况

接口：

`GET /cost/project-basic/page`

请求参数：

| 字段 | 示例 |
|---|---|
| `pageNo` | `1` |
| `pageSize` | `10` |
| `projectId` | `1001` |

预期：

- 返回 `projectId = 1001` 下的项目基本情况。
- 种子数据中应有 2 条。

### 4.5 查询工作令基础信息

接口：

`GET /cost/work-order/page`

请求参数：

| 字段 | 示例 |
|---|---|
| `pageNo` | `1` |
| `pageSize` | `10` |
| `projectId` | `1001` |

预期：

- 返回 `projectId = 1001` 下的工作令基础信息。
- 种子数据中应有 3 条。
- `WO-LA-001-01` 的 `bookCostAmount` 大于 `productTargetCost` 10%，可触发超支预警样本。

### 4.6 查询预警记录

接口：

`GET /cost/warning/page`

请求参数：

| 字段 | 示例 |
|---|---|
| `pageNo` | `1` |
| `pageSize` | `10` |
| `warningLevel` | `OVER` |

预期：

- 返回 5 条超支预警样本。
- 包含推送状态 `PUSHED`、`NOT_PUSHED`、`FAILED`。

## 5. 写入用例

### 5.1 新增项目基本情况

接口：

`POST /cost/project-basic/create`

请求体示例：

```json
{
  "projectId": 1002,
  "subsystemName": "测试分系统",
  "userName": "项目办测试用户",
  "acquireMethod": "竞争择优",
  "batchCategory": "B02/测试",
  "platformSeries": "商业运载系列",
  "researchUnitId": 2099,
  "researchUnitName": "外网测试承研单位",
  "targetPrice": 1200.00,
  "contractAmount": 1180.00,
  "targetCostAmount": 980.00,
  "cycleStart": "2026-06",
  "cycleEnd": "2026-12",
  "stageCode": "M",
  "basicInfo": "外网联调新增样本",
  "status": "DRAFT",
  "remark": "联调用例"
}
```

预期：

- 返回新增记录 `id`。
- 再调用 `/cost/project-basic/get?id=` 可查询到该记录。

### 5.2 编辑项目基本情况

接口：

`PUT /cost/project-basic/update`

请求体：

- 使用 5.1 返回的 `id`。
- 修改 `targetCostAmount`、`remark`。

预期：

- 返回 `true`。
- `updateTime` 更新。

### 5.3 删除项目基本情况

接口：

`DELETE /cost/project-basic/delete?id={id}`

预期：

- 返回 `true`。
- 再次分页查询不返回该记录。

### 5.4 新增工作令基础信息

接口：

`POST /cost/work-order/create`

请求体示例：

```json
{
  "projectId": 1002,
  "unitId": 2099,
  "unitName": "外网测试研制单位",
  "workOrderNo": "WO-TEST-001",
  "workOrderName": "外网测试工作令",
  "productTargetCost": 900.00,
  "bookCostAmount": 1010.00,
  "stageCodes": "M,C",
  "maxStageCode": "C",
  "subsystemName": "测试系统",
  "productShortName": "测试产品",
  "quantity": 2,
  "verticalDivision": false,
  "status": "DRAFT",
  "remark": "联调用例"
}
```

预期：

- 返回新增记录 `id`。
- 再调用 `/cost/work-order/page?projectId=1002` 可查询到该记录。

### 5.5 工作令编号重复校验

接口：

`POST /cost/work-order/create`

请求体：

- 再次使用 `workOrderNo = WO-TEST-001`。

预期：

- 返回业务错误：工作令编号已存在。

### 5.6 编辑/删除工作令基础信息

接口：

- `PUT /cost/work-order/update`
- `DELETE /cost/work-order/delete?id={id}`

预期：

- 编辑返回 `true`。
- 删除后分页查询不再返回该记录。

## 6. 导入导出用例

### 6.0 本地联调路径说明

- `cost-server` 独立启动时，业务接口实际路径为 `/admin-api/cost/...`。
- 文档中保留的 `/cost/...` 是 Controller 内部路径；前端和 HTTP 工具联调时应使用 `/admin-api/cost/...`。
- 外网单服务测试如未启动 `system-server`、`infra-server`，需要启用默认关闭的 `COST_LOCAL_TEST_MOCK_PLATFORM=true` 后再测业务接口。
- 该开关只用于外网测试验证导入、导出、CRUD 链路；内网环境必须关闭并接入真实中台认证、租户和权限。

### 6.1 下载项目基本情况模板

接口：

`GET /admin-api/cost/project-basic/get-import-template`

预期：

- 返回 Excel 文件。
- 模板字段应与项目基本情况导入字段一致【需确认】。

### 6.2 导入项目基本情况

接口：

`POST /admin-api/cost/project-basic/import`

请求：

| 字段 | 示例 |
|---|---|
| `file` | Excel 文件 |
| `updateSupport` | `true` |

预期：

- 返回 `CostImportResultRespVO`。
- 成功时 `status = SUCCESS`。
- 部分失败时返回 `errors` 行号和原因。

### 6.3 工作令模板、导入、导出

接口：

- `GET /admin-api/cost/work-order/get-import-template`
- `POST /admin-api/cost/work-order/import`
- `GET /admin-api/cost/work-order/export-excel`

预期：

- 行为与项目基本情况一致。
- 工作令导入必须校验 `workOrderNo` 非空且唯一。

### 6.4 2026-05-17 本地 HTTP 联调记录

联调前提：

- `cost-server` 独立启动，端口 `48108`。

- 请求头使用 `login-user` 和 `tenant-id: 1` 模拟已登录租户用户。

## 7. 状态和预警用例

### 7.1 提交项目状态

接口：

`PUT /cost/project/update-status`

请求体示例：

```json
{
  "id": 1002,
  "auditStatus": "SUBMITTED",
  "statusScope": "PROJECT",
  "comment": "外网测试提交"
}
```

预期：

- 返回 `true`。
- 项目 `auditStatus` 更新为 `SUBMITTED`。
- 状态粒度是否拆成项目基本情况/工作令分别提交仍需确认【需确认】。

### 7.2 推送预警

接口：

`POST /cost/warning/push`

请求体示例：

```json
{
  "ids": [6002, 6004],
  "receiverScope": "ALL",
  "remark": "外网测试全部推送"
}
```

预期：

- 返回成功/失败数量。
- 成功记录 `pushStatus` 更新为 `PUSHED`，并写入 `pushedTime`。
- 真实消息中心是否只写消息表，还是调用其它通道，仍需技术确认【需确认】。
