# 接口联调用例

状态：历史 MVP 用例保留；当前本地授权用例见文末 [2026-09-08 增补](#local-auth-cases)。

## 1. 目标

记录外网测试阶段的接口调用顺序、示例参数和预期返回，方便后续生成 Postman / Apifox 用例，也方便前端页面逐步联调。

本文件只记录接口用例，不记录数据库账号密码。数据库连接信息见 `80-deployment/00-环境账号与敏感信息.md`。

## 2. 前置条件

- 外网 MySQL `costree_mvp` 已执行 `30-data/schema-mvp.sql`。
- 外网 MySQL `costree_mvp` 已执行 `30-data/seed-mvp.sql`。
- 当前测试数据包含：
  - 主业项目 `1001`：`ZY-2026-LA-001`，有项目基本情况、工作令和预警样本。
  - 主业项目 `1003`：`ZY-2026-DW-001`，有多阶段工作令和超支样本。
  - 主业项目 `1005`：`ZY-2026-ST-001`，有已审批项目基本情况和工作令样本。
  - 主业项目 `1007`：`ZY-2026-SP-001`，有推送成功、失败、未推送预警样本。

## 3. 推荐联调顺序

| 顺序 | 用例 | 目标 |
|---|---|---|
| 1 | 查询型号树 | 验证菜单筛选基础数据 |
| 2 | 查询成本项目列表 | 验证项目入口页 |
| 3 | 查询项目锚定信息 | 验证项目办/研制单位页面左侧只读信息 |
| 4 | 查询项目基本情况 | 验证项目办维护页 |
| 5 | 查询工作令基础信息 | 验证研制单位维护页 |
| 6 | 查询预警记录 | 验证 10% 超支样本 |
| 7 | 新增/编辑/删除项目基本情况 | 验证 CRUD |
| 8 | 新增/编辑/删除工作令基础信息 | 验证 CRUD 和工作令编号唯一性 |
| 9 | 下载模板/导入/导出 | 验证 Excel 链路 |
| 10 | 推送预警 | 验证外网全部推送测试链路 |

## 6. 导入导出用例

### 6.0 本地联调路径说明

- `cost-server` 独立启动时，业务接口实际路径为 `/admin-api/cost/...`。
- 文档中保留的 `/cost/...` 是 Controller 内部路径；前端和 HTTP 工具联调时应使用 `/admin-api/cost/...`。
- 外网单服务测试如未启动 `system-server`、`infra-server`，需要启用默认关闭的 `COST_LOCAL_TEST_MOCK_PLATFORM=true` 后再测业务接口。
- 该开关只用于外网测试验证导入、导出、CRUD 链路；内网环境必须关闭并接入真实中台认证、租户和权限。

接口：

`GET /admin-api/cost/project-basic/get-import-template`

预期：

### 10.2 角色管理四个接口

先查询平台账号（两种查询方式二选一）：


下例假设目标无本地记录、无成本角色。名称需 URL 编码；传正 userId 时优先使用 ID。


对应的三种响应示例（项目最多 50 条；单位筛选参数不生效）：


```json
{"code":0,"msg":"","data":[{"manageUnitCode":"U_TEST","manageUnitName":"测试管理单位"}]}
```

```http
GET /cost/access-scope/profile?userId=20001
```

```json

```

### 10.4 撤销与其他角色范围

撤销前重新 lookup 获取当前 revision；如果当前仍为 1，请求为：

```http
PUT /cost/role-assignment/assign
Content-Type: application/json
```

```json
{"userId":20001,"roleCode":null,"revision":1}
```

成功后再 lookup：source=COST、revision=2、costRoleCodes=[]；page 仍保留该目标，scope-user-page 不再返回该目标；再次读取档案时三类范围为空，目标登录 me 应未获得成本业务授权。不得删除本地撤销记录以“恢复平台角色”。

对其他业务角色，先通过 assign 切换并重读档案，以下仅列 PUT profile 请求体。数字 3 和 5 仅示例，应替换为实际 roleRevision 和 scopeRevision；角色切换会清空旧范围。

科研部：

```json
{"userId":20001,"roleRevision":3,"scopeRevision":5,"domainCodes":["D_TEST"],"projectCodes":[],"manageUnitCodes":[]}
```

项目办：

```json
{"userId":20001,"roleRevision":3,"scopeRevision":5,"domainCodes":[],"projectCodes":["P_TEST"],"manageUnitCodes":[]}
```

全局查看者无需保存显式范围；若测试清理旧范围，使用三个空数组。它仍是只读业务角色，不获得授权管理能力。
