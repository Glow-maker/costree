# 授权专员用户目录及身份展示修复


### 2026-09-10：授权专员查看当前租户全部账号（本地源码，未部署）

本节替代前文“只列成本库已接管用户”的列表限制。`GET /cost/role-assignment/page` 与 `/scope-user-page` 均返回当前租户中台账号，包含未分配成本角色、旧中台角色、管理员、授权专员和停用账号。支持按登录账号或姓名包含查询、按用户 ID 升序分页。

新增 UserVO 字段：`roleName`（管理员/成本授权专员身份）、`canAssignRole`、`restrictionReason`。管理员、专员、自身及停用账号显示在列表中，但现有写入保护继续生效。角色分配及数据范围保存接口仍在服务端校验，不以 UI 禁用代替鉴权。

数据授权页可直接保存成本角色，再配置范围。角色变更或撤销仍清除原范围；全局查看和授权专员无需业务范围。GET profile 允许管理者查看同租户受保护账号身份；成本授权专员显示正确身份和说明，混配业务角色仍提示冲突。保存范围继续禁止专员修改自己、管理员和其他专员。

为兼容旧 system，复用 `AdminUserApi.listByNameLike("")`，只忽略部门范围，保留租户隔离；不增加 system 接口或数据库结构。目前旧 RPC 返回目录后由 cost 过滤分页，并非远端数据库分页。真实旧中台 RPC 的租户隔离、账号覆盖和大目录性能仍待验收。

验证：新增目录含未分配账号/专员/停用账号、稳定分页、姓名搜索、先鉴权后读取目录、专员身份与只读目标、混配角色冲突测试。前端 TypeScript 与 ESLint 通过。后端六组测试共 44 项，0 失败、0 错误；最终两组涉及本次变更的测试已重跑通过。未执行真实库 SQL、未修改 system、未打包提交部署。
