# 成本权限：中台页面勾选清单

适用：PG 成本业务库已升级，DM 中台权限通过页面维护，不直接执行 DM 修改 SQL。

## 一、四类业务角色

在「系统管理 → 角色管理」创建或检查以下角色；状态开启，通用数据权限设为“仅本人”。成本范围在成本数据授权页单独配置，不使用中台部门数据权限代替。

| 显示名称（可调整） | 角色标识（必须完全一致） |
|---|---|
| 成本全局查看 | `cost_global_viewer` |
| 成本科研部 | `cost_research_department` |
| 成本项目办 | `cost_project_office` |
| 成本研制单位 | `cost_unit_user` |

普通业务账号只分配其中一种成本业务角色。不得用管理员角色代替。原来其他模块的角色保持不变。

## 三、业务部门的“成本授权专员”

新增第五种管理角色（不是第五种成本业务角色）：

| 配置 | 值 |
|---|---|
| 名称 | 成本授权专员 |
| 标识 | `cost_role_allocator` |
| 状态 | 开启 |
| 通用数据权限 | 仅本人 |
| 上表 21 个成本业务按钮 | **全部不勾选** |
| 系统用户、角色、菜单维护权限 | **全部不勾选** |

管理员通过中台「用户管理 → 分配角色」将该角色交给业务部门专用账号；该账号不要再混配其他角色。授权专员不能给自己修改角色，不能分配管理员、授权专员或其他中台角色。

专用页面按角色标识校验，不需要授予 `system:permission:assign-user-role` 等通用接口权限：

1. `/cost/role-assignment`：给同租户已有用户分配/切换/移除四类成本业务角色；不改变其他中台角色。
2. `/cost/back/access-scope`：为上述用户配置领域、项目、管理单位；与管理员的成本数据范围授权内容一致。
3. 不开放成本首页、成本树、金额明细、填报、预警处置、系统用户和角色管理。登录、退出、必要的账户功能不属于业务授权范围。

工作顺序：**管理员创建用户和初始化角色 → 授权专员分配业务角色 → 授权专员设置数据范围 → 用户退出重新登录验证**。

| 业务角色 | 数据范围 |
|---|---|
| 全局查看 | 无需单独配置；授权专员选择此角色前应确认业务审批 |
| 科研部 | 单个领域 |
| 项目办 | 一个或多个项目 |
| 研制单位 | 项目与管理单位交集，两者都要配置 |

切换角色后必须核对旧数据范围；未配置所需范围的账号不能访问对应成本数据。停用账号、管理员及授权专员不在角色分配候选中。数据授权列表仅显示具有四类成本业务角色的普通用户，其他模块用户不显示；冲突账号仍显示以便修正。

上述精简页面和成本用户筛选仅适用于授权专员。超级管理员、租户管理员继续使用原中台「用户管理」「角色管理」页面；成本数据授权页保留原用户列表及这两个管理按钮。管理员打开 `/cost/role-assignment` 时自动转到 `/system/user`，不使用专员精简页替代原有管理功能。

## 四、预警站内信别遗漏

中台「站内信模板管理」通过页面新增/检查四个启用模板，编码不可修改：

- `COST_WARNING_PENDING_DISPOSITION`
- `COST_WARNING_FEEDBACK_SUBMITTED`
- `COST_WARNING_RETURNED`
- `COST_WARNING_CLOSED`

模板正文与参数以发布包中的站内信模板脚本为准复制到表单，不需要执行 DM SQL。模板管理由平台管理员完成，不交给成本授权专员。

## 五、上线边界

本清单中的授权专员与筛选接口纳入 **20260907-business-authorization 新部署包**。早先的0907包不含这些功能，应按 RELEASE-INFO 中的 releaseRevision 区分。

需要更新：**前端 + cost-server + system-server（中台服务）**。不新增 PG/DM 业务表或字段，不需要直接修改 DM 数据库；第五种角色通过页面创建。

不能仅创建角色就期待旧服务支持新页面。必须同时部署新前端、cost-server 和 system-server，再按上述步骤交接业务部门；真实内网越权、缓存和双服务授权流程仍需验收。
