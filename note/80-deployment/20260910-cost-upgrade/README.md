# 20260910 成本库修复 SQL

本目录是 SQL 交付，不是新的离线应用包。仅针对 PostgreSQL / GaussDB(DWS) 成本 schema，不适用于 MySQL、DM 或 system 库。

## 文件与执行顺序

| 文件 | 用途 |
| --- | --- |
| `01-full-upgrade.sql` | 已有成本库的完整升级：先根据实际结构补缺失表、列，再执行必要的历史数据迁移、索引修补、授权版本字段及校验。结构补齐不依赖 migration 版本号。 |
| `02-backup-create-missing-tables.sql` | 备用补表：逐表判断是否存在，只为缺失表创建当前结构、必要序列和注释。已有表整体跳过，不补列、不改数据、不清 migration、不重置序列。 |
| `03-verify-structure.sql` | 只读核对目标环境、20 张表及授权关键字段。 |
| `SHA256.json` | 三个 SQL 文件的 SHA256。修改 schema/租户后，修改副本的校验值自然不同。 |
| `local-validation.json` | 独立 PostgreSQL 9.2.23 / 17.11 容器的执行结果，不代表 DWS 验收。 |

通常直接执行 **01 → 03**；01 已包含补表，无需先跑备用脚本。只有需要单独恢复缺表时使用 02，随后仍应完成 01 和 03。02 不替代完整升级，特别是旧 `cost_auth_user_lock` 已存在但缺 `revision` 时，必须由 01 补列。

执行前备份并停止 cost 写入。每个 SQL 开头的 `search_path` 默认是 `"public"`，必须改为 **cost 后端实际连接的 schema**；数据库名和 schema 不是一回事。01 中 `tenant_id=124` 是项目归属检查，请按实际租户修改。不要全局替换数据库名或盲目修改全部数字。

客户端使用“遇错停止”，整份执行。01/02 各自只有一个外层事务；仅在没有 ERROR 且 COMMIT 成功时算完成。报错后先结束失败事务（ROLLBACK），保留第一条 ERROR；不要继续跳行执行，也不要清空 migration 记录。

## 覆盖范围与保护边界

覆盖当前 20 张成本表，包括：

- 本地角色：`cost_user_role`、`cost_user_role_action`、`cost_auth_user_lock`。
- 数据范围：`cost_user_project_scope`、`cost_user_domain_scope`、`cost_user_unit_scope`。
- 项目、工作令、单位明细、单位字典、子系统字典、预警及接收/操作记录等现有成本结构。

备用脚本会创建缺表所依赖的序列；主键/表内约束随 CREATE TABLE 建立。它不删除已有对象，不插入角色或业务记录。创建的是空表，不能恢复已丢失的授权数据；若原表被误删，应从备份恢复数据。

完整脚本保留历史业务数据迁移的版本保护，避免重复归并已有数据；**补表、缺列、缺索引不受这些版本保护影响**。已有字段的类型、默认值、错误约束不会被强行重写；遇到无法安全补齐的 NOT NULL 字段、重复业务键或目标租户不符，会报错回滚，不编造业务值。历史数据迁移可能更新旧记录，不能把 01 当作“只建表”脚本。

已移除预警迁移中的 `pg_temp.costree_add_warning_column` 调用；缺列检查和 ALTER 使用同一目标 schema。DWS 分支保留行存、按分布键建表及兼容索引方式，但本次没有真实 DWS 实例执行证据。

## 必须配套的应用修改

此次并发修复新增的是授权锁表字段 `cost_auth_user_lock.revision bigint NOT NULL DEFAULT 0`，不新增业务金额/项目/工作令字段。完整脚本还会补齐旧库原本缺少的历史业务字段。

GET profile 返回 `scopeRevision`；保存范围必须原样带回。cost 内角色或范围保存成功都会递增该值，旧页面再次保存会被拒绝。角色自身的 `roleRevision` 继续独立校验。旧前端不带 `scopeRevision` 将无法保存，需要匹配本次代码的前端资源。

三个范围表的 `id = NULL` 修复在后端 `ASSIGN_ID` 逻辑中，**单独执行 SQL 不能修复旧 JAR 显式插入 NULL**。后续制作离线包时必须构建最新 cost JAR，并核验用户提供的前端压缩包包含配套改动。本次没有构建/替换 JAR 或前端压缩包。

收益率仅更名，保留原账面成本/到款计算；院内指标仍使用院内金额。不改成利润率。
