# 成本树详情页阶段与单位视角设计

状态：进行中

## 本轮目标

页面：`/cost/tree-detail?projectCode=xxx`

本轮将成本树详情页从原第一版“型号 -> 系统 -> 产品/工作令”调整为任务书口径下的“型号 -> 单位”，并增加阶段控制、型号右侧项目成本组成饼图和单位点击后的独立详情页。

## 业务口径

- 默认打开页面时，不选择阶段，表示“全部汇总”。
- 用户可在右上角阶段下拉框中选择单个或多个阶段。
- 武器领域阶段顺序暂按 `M -> C -> S -> D`。
- 宇航、运载、卫星、空间类阶段顺序暂按 `M -> C -> Z`。
- 一个工作令如果覆盖多个阶段，展示和汇总时计入最终阶段：
  - 优先使用 `cost_work_order.max_stage_code`；
  - 没有最高阶段时，按领域阶段顺序从 `stage_codes` 推断最后阶段。
- 型号根节点同步展示当前阶段口径，便于用户观察阶段切换效果。
- 主成本树页面只显示两层：型号根节点、单位节点。
- 院内单位作为型号下二级节点，点击后进入单位详情页查看该单位下的工作令。
- 院外单位作为型号下二级汇总节点，不展示工作令，点击后进入单位详情页查看所有院外单位信息。
- 院内/院外分类以 `cost_unit_dict.inside_institute` 为准，不再靠单位名称猜测。

## 数据来源

### 树节点

- 型号根节点：`cost_project`
- 院内单位节点：由 `cost_work_order.unit_name` 聚合生成，并通过 `cost_unit_dict` 判断是否院内。
- 院外单位节点：由 `cost_unit_cost_detail.unit_name` 聚合生成，并通过 `cost_unit_dict` 判断是否院外。
- 工作令明细：不再出现在主成本树页面；进入 `/cost/tree-unit-detail?projectCode=xxx&unitName=xxx&unitCategory=INNER` 后展示。
- 目标成本：`cost_work_order.product_target_cost`
- 账面成本：当前页面仍使用 `cost_work_order.book_cost_amount`；业务方建表参考已新增 `cost_work_order_ledger_detail`，后续正式口径应改为按凭证明细和工作令阶段聚合【需确认聚合口径】

### 业务方源数据表

本轮根据业务方建表参考补充三张源数据表，但暂不改变当前页面接口：

- `cost_source_project_tree`：源主业项目树，保留 `xmnm`、父路径、级数、自定义字段和源最后修改时间。
- `cost_work_order_project_ref`：工作令关联主业项目字典，保留源工作令与项目映射、核算单位和年度。
- `cost_work_order_ledger_detail`：工作令账面成本凭证明细，后续用于计算账面成本。

页面后续演进路径：

1. 项目与树节点归属优先从 `cost_source_project_tree` 同步到 `cost_project` / `cost_model_node`。
2. 工作令归属优先从 `cost_work_order_project_ref` 同步到 `cost_work_order`。
3. 账面成本从 `cost_work_order_ledger_detail` 按 `work_order_no` / `resolved_stage_code` 聚合，逐步替代测试字段 `book_cost_amount`。

### 单位字典

新增 `cost_unit_dict` 作为院内/院外分类和单位信息展示来源，字段按业务截图第一版落库：

- 核算单位 ID：`accounting_unit_id`
- 核算单位编号：`accounting_unit_code`
- 核算单位名称：`accounting_unit_name`
- 管理单位编号：`manage_unit_code`
- 管理单位名称：`manage_unit_name`
- 往来单位编号：`contact_unit_code`
- 往来单位名称：`contact_unit_name`
- 是否集团内：`inside_group`
- 是否八院内：`inside_institute`
- 单位 ID：`unit_id`

当前只提供只读接口 `GET /cost/unit-dict/list`，维护页后续再补【需确认】。

### 成本组成饼图

当前复用 `cost_unit_cost_detail` 六类成本结构：

- 薪酬：`salary_amount`
- 材料费：`material_amount`
- 外协费：`outsource_amount`
- 管理费：`manage_amount`
- 燃料动力：`fuel_power_amount`
- 其他：`other_amount`

后端 `GET /cost/overview/unit-detail` 已扩展筛选参数：

- `domainCode`
- `projectCode`
- `unitName`
- `stageCodes`：多个阶段用逗号分隔

页面右侧“项目成本组成”按当前项目和当前阶段实时查询并前端汇总成饼图。

## 需确认

- 【需确认】`cost_unit_dict` 后续是由成本库维护，还是定时同步中台/湖仓协作单位字典。
- 【需确认】院外单位目前从 `cost_unit_cost_detail` 展示合同、到款、目标和账面成本；任务书中的“院外单位合同金额、目标成本、到款金额来自表格1”还需要明确正式来源表和字段。
- 【需确认】任务书表格4的成本组成口径可能是八类，当前 MVP 表是六类。正式导入前需要确认八类到六类的映射，或扩展 `cost_unit_cost_detail` 字段。
- 【需确认】正式展示页是否只展示 `APPROVED` 数据。当前外网演示仍展示已有测试数据，未强制过滤审批通过状态。
- 【需确认】源账面成本 `je` 的单位、借贷方向和冲销金额是否按正负数直接汇总。
- 【需确认】工作令关联主业项目字典变更时，历史凭证明细按原映射追溯还是按当前映射重算。
