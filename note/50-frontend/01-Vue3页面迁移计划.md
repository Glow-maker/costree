## 页面拆分口径

- 原型里的 `Table 2` 不作为最终页面名，落为项目办使用的“项目基本情况维护”。
- 原型里的 `Table 3` 不作为最终页面名，落为研制单位使用的“工作令基础信息维护”。
- 成本项目列表负责选择项目和进入对应维护页。
- 两个维护页面都展示同一套主业项目锚定信息，但维护区、按钮、接口和权限点分开。

## 前台/后台路由拆分

| 类型 | 路由 | 说明 |
|---|---|---|
| 前台门户 | `/cost/index` | 成本库汇总展示页，不带中台左侧菜单 |

| 后台管理 | `/cost/back/project-basic` | 项目基本情况维护，使用中台 `Layout` |
| 后台管理 | `/cost/back/work-order` | 工作令基础信息维护，使用中台 `Layout` |
| 兼容跳转 | `/cost/project-basic` | 旧地址跳转到 `/cost/back/project-basic` |
| 兼容跳转 | `/cost/work-order` | 旧地址跳转到 `/cost/back/work-order` |

## 迁移原则

- 不直接嵌入 React 原型。
- 使用 Vue3 + Element Plus + 中台现有请求封装。
- 按中台已有列表、表单、导入导出样式实现。
- 按权限点控制按钮显示。
- 开发在 `costree-frontend` 中进行，完成后再合并回内网中台前端。
- MVP 不做复杂字段级权限，页面和按钮按角色拆分。
