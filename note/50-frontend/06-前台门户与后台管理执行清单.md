# 前台门户与后台管理执行清单

状态：执行中

## 1. 本轮目标

把成本库从“只有后台维护页面”的状态，推进到“前台用户门户 + 后台管理维护”两类入口并存。

本轮不一次性完成全部 React/Figma 原型页面，优先完成可访问、可演示、可继续迭代的骨架：

- 前台入口：`/cost/index`
- 前台目录：`/cost/catalog`
- 后台维护：`/cost/back/project-basic`
- 后台维护：`/cost/back/work-order`
