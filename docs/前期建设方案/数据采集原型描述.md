本模块以主业项目为核心对象，采用“左侧锚定信息、右侧业务维护”的页面结构。左侧固定展示院层级基础信息（Table 1），由系统自动拉取，不参与人工录入，用于锚定当前主业项目。右侧分别承载项目办维护的项目基本情况表（Table 2）和研制单位维护的工作令基础信息表（Table 3）。其中，Table 2 与 Table 3 均支持在当前主业项目上下文下进行新增、编辑、删除、批量维护、导入、导出、检索及手动录入；Table 3 支持跨主业工作令新增，但必须先明确选择主业项目，主业项目编号和名称不得为空。模块同时支持保存草稿、提交审批、审批流程可视化以及版本留痕。

# 1. 建设目标

本模块用于围绕**主业项目**开展成本树相关数据采集与维护，形成“系统锚定信息 + 项目办填报 + 研制单位填报 + 审批流转”的完整业务闭环。

模块共包含三部分数据：

- **Table 1：院层级基础信息**
   由系统自动拉取，不允许人工录入，用于锚定当前主业项目，作为 Table 2 与 Table 3 的上下文基础。
- **Table 2：项目基本情况表**
   由**项目办**维护。在固定主业项目编号、主业项目名称后，对该主业项目下的项目基本情况记录进行维护，支持批量维护、导入、导出、检索、手动录入。
- **Table 3：工作令基础信息表**
   由**研制单位**维护。在固定主业项目编号、主业项目名称后，对该主业项目下的工作令记录进行维护，支持批量维护、导入、导出、检索、手动录入。

------

# 2. 角色分工

## 2.1 项目办

负责维护 Table 2 项目基本情况表，保存草稿并提交审批。

## 2.2 研制单位

负责维护 Table 3 工作令基础信息表，支持单条录入和批量维护。

## 2.3 成本中心/管理员

负责系统初始化数据、历史数据导入、数据推送、模板维护等。

## 2.4 审批角色

包括：

- 项目办初审
- 财务部会签
- 科研部会签
- 型号两总审批

------

# 3. 总体页面架构

模块整体建议采用：

## **左侧固定锚定信息 + 右侧业务维护区**

### 左侧固定区

展示 Table 1 的主业项目锚定信息，所有详情页保持一致。

### 右侧业务区

按页签或菜单切换：

- 项目基本情况表（Table 2）
- 工作令基础信息表（Table 3）

### 页面底部或右侧抽屉

展示审批流程、审批记录、驳回原因等。

------

# 4. 页面清单

建议原型至少包含以下页面：

## P1 项目列表页

用于检索并进入某个主业项目的数据采集详情。

## P2 项目详情页 - 项目基本情况表（Table 2 列表页）

左侧固定锚定信息，右侧为项目基本情况维护列表。

## P3 项目基本情况新增/编辑页（Table 2 抽屉/弹窗）

用于新增或编辑单条项目基本情况记录。

## P4 项目详情页 - 工作令基础信息表（Table 3 列表页）

左侧固定锚定信息，右侧为工作令维护列表。

## P5 工作令新增/编辑页（Table 3 抽屉/弹窗）

用于新增或编辑单条工作令记录。

## P6 导入/导出/批量维护页或弹窗

支持 Table 2 与 Table 3 的批量操作。

## P7 审批流程查看页/侧边栏

用于查看审批节点、状态、审批意见及驳回原因。

# 6. Table 1 设计说明

## 6.1 页面定位

Table 1 不作为独立重点录入页，而作为详情页左侧固定锚定区使用。

## 6.2 数据来源

全部由系统自动拉取。

## 6.3 是否可编辑

不可编辑。

## 6.4 用途

- 锚定当前主业项目
- 为 Table 2 与 Table 3 提供上下文
- 避免用户在填报过程中丢失当前项目语境

## 6.5 建议展示方式

采用固定信息卡片方式展示，而不是单独完整大表。

# 7. 通用按钮说明

## 保存草稿

保存当前录入内容，不进入审批流程。

## 提交审批

将当前数据提交至审批流程，提交前进行完整校验。

## 新增

新增一条记录。

## 编辑

修改一条已有记录。

## 删除

删除一条记录，删除前弹确认框。

## 批量维护

对多条勾选记录统一更新指定字段。

## 导入

通过模板导入批量数据。

## 导出

导出当前列表或全部数据。

## 版本对比

对比当前版本与上一版本字段差异。

------

# 8. 通用校验规则

## 8.1 格式规则

- 金额单位统一为万元，保留2位小数
- 日期字段统一格式为 YYYY-MM
- 数量字段为正整数

## 8.2 必填规则

所有业务要求字段必须校验非空。

## 8.3 唯一性规则

工作令编号必须唯一。

## 8.4 逻辑规则

- 周期结束时间不能早于开始时间
- 跨主业工作令必须明确主业项目，不允许空主业字段
- 阶段取值必须符合对应领域字典

------

# 9. 原型绘制建议

## 9.1 页面风格建议

- 左侧固定信息面板宽度保持统一
