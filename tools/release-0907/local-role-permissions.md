# 仅部署cost的权限交接清单

## 管理员一次性操作

1. 中台`系统管理→角色管理`创建或检查角色：名称“成本授权专员”，标识 **cost_role_allocator**，状态开启，通用数据权限“仅本人”。
2. **不勾任何成本业务按钮，不勾系统用户、角色、菜单管理权限**。无需给专员单独菜单；成本门户根据该角色提供入口。
3. 中台`用户管理`创建/选择业务部门专用账号，分配上述专员角色，不混配管理员和四类成本角色。
4. 用户仍在中台创建、停用；四个通知模板由管理员按同目录02清单配置。

## 专员日常操作

1. 登录后选择成本树平台，进入“角色分配”。
2. 新账号点“查找中台用户”，用用户名称（姓名）或ID查找，核对登录账号与姓名。
3. 选择下表一种角色，保存。分配记录写成本PG，不改DM。
4. 点“配置数据范围”，选择用户后授权并保存。
5. 让用户退出重新登录验证；需要收回权限则清空角色并保存，不删除数据库记录。

| 成本角色 | 能力 | 要配置的数据范围 |
|---|---|---|
| 全局查看 cost_global_viewer | 查看及导出，不填报、不处置 | 全成本范围，分配前确认业务审批 |
| 科研部 cost_research_department | 授权领域查看、全周期经费填写及导出 | 单个领域 |
| 项目办 cost_project_office | 基础填报、查看导出、预警推送和闭环 | 一个或多个项目 |
| 研制单位 cost_unit_user | 工作令填报、查看导出、被指定预警反馈 | 项目与管理单位交集，两项都配 |

本地接管账号固定使用上述能力。**不必在中台创建/分配四类同名角色，也不必逐项勾21个菜单按钮。** 系统不会把这些成本权限写进中台的通用权限缓存，不影响其他模块。

老账号未接管时，原中台角色和按钮权限继续生效；其旧配置不要批量取消。专员可以查找老账号并保存，完成逐个接管。接管后再修改中台旧角色不会改变成本权限，需在成本页操作。

管理员仍看到原中台用户/角色管理和原数据授权列表。为管理已接管账号，可另进“成本角色分配”页。专员不能修改自己、管理员或其他专员，不能授予其他中台角色。

## 六类身份验收

管理员原页面可用；专员只能分配角色和数据范围；全局查看不可填报；科研部只见指定领域；项目办只见授权项目；研制单位只见项目×单位交集。特别验证：撤销后即使中台仍有旧成本角色，也不能调用成本查询/导出接口。
