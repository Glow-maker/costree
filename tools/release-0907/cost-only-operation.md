# 0907 精简部署：只部署成本模块

本包只保留现场必用文件：一个成本 JAR、一份前端 ZIP、成本 SQL 生成器和页面权限清单。不包含 system JAR、不包含重复展开的前端资源，也不包含 DM 写库脚本。

## 依次执行

1. **备份并停写**：暂停帕科同步，备份成本库、旧成本 JAR、前端及原配置。不要停止或替换 system 服务。
2. **生成成本 SQL**：打开 `01-成本库升级/部署参数生成器.html`，填真实租户 ID、成本 schema，下载三份 SQL。schema 不确定先执行同目录的只读识别脚本。
3. **在 PG9.2/DWS 成本库执行**：01只读检查 → 02合并升级 → 03升级验收。客户端设置遇错停止。第一次 ERROR 后停止并回滚，保留首条错误；不要清业务数据。结构版本仍为20260820，日期变更不意味着重建。
4. **替换成本应用**：按 `03-应用文件/00-应用替换说明.md` 替换 cost-server.jar 和整个前端。保留原配置及网关；不替换 system。
5. **管理员配置权限**：按 `02-页面权限配置/01-权限勾选与专员操作清单.md` 的四类业务角色清单配置，通过原中台用户管理分配角色，再到 `/cost/back/access-scope` 授权领域、项目和管理单位。不要创建或交付授权专员账号。
6. **管理员配置站内信**：按 `02-页面权限配置/02-站内信模板逐项复制.md` 在中台页面配置四个模板，不执行DM写库SQL。
7. **重新登录验收**：管理员原页面可用；全局查看、科研部、项目办、研制单位各自范围正确，越权被拒绝；验证填报、预警推送→说明反馈→闭环、型号比对、3D。不通过先停止切换，按备份回退应用。通过后恢复原调度。

## 本包暂不支持的功能

**授权专员自助分配角色和用户筛选依赖新增 `/system/cost-role-assignment/*` 接口。本次不更新 system，所以不能承诺该功能可用。** 前端沿用用户原始 ZIP，仍含专员页面代码，但不得给用户分配 `cost_role_allocator` 并交付使用。角色和数据范围暂由超级管理员用原页面维护；不是给专员勾选几个菜单就能解决。

成本服务仍依赖现场已有的中台登录、用户角色及站内信服务；“只部署cost”并非脱离中台独立运行。若现场既有接口不兼容，应停止并记录错误，不扩大权限绕过。

## 保持不变

- 不直接修改DM；页面保存后账号重新登录，通常不需要手工清Redis，禁止FLUSHDB/FLUSHALL。
- 现有每日同步保持“清六张中间表 → 源全量装载 → 检查 → 业务UPDATE＋INSERT → 重算 → 验收”；不清业务表，不覆盖填报、数据授权或预警历史。本包不重配现有源映射。
- 前端无须内网安装Node.js，3D无须新增SQL。整个ZIP解压部署，不能只替换index.html或几个JS。
- SQL沿用已通过独立PG9.2测试的生成器；真实DM/DWS与只部署cost的联调尚需现场验收，不能把静态验包当作生产验收。
