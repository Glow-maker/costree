# 0907 现场操作卡：权限全部用页面配置

**只按本卡操作；不要遍历整包 SQL。首次导入权限不需要直接修改 DM。**

入口是完整部署包的 `00-现场必用` 文件夹。子目录中的材料可单独携带，应用文件无需联网安装依赖。保留完整包用于验包、启动配置参考及异常诊断。

| 顺序 | 执行位置 | 只做这些 | 通过标志 |
|---|---|---|---|
| 1 | 运维 | 暂停帕科调度、停止成本写入；备份成本库、旧前端及成本/中台 JAR 和配置。安排中台服务更新窗口 | 备份可恢复 |
| 2 | 本机浏览器 | 打开 `01-成本库升级/部署参数生成器.html`；填写真实租户 ID 和成本 schema，下载三份 SQL | 生成01、02、03；无报错 |
| 3 | **PG9.2/DWS成本库** | 按 01只读检查 → 02合并升级 → 03验收，分别整段执行，客户端遇错停止 | 无 ERROR，事务提交，结构版本20260820及验收通过 |
| 4 | 应用服务器 | 按 `03-应用文件/00-应用替换说明.md` 换成本 JAR、中台 JAR、整个前端 | 原配置保留、服务健康、无缺类/缺表 |
| 5 | 中台管理员页面 | 按 `02-页面权限配置/01-权限勾选与专员操作清单.md` 配四类业务角色的按钮权限，并创建授权专员角色 | 四类业务按钮8/8/12/10；专员无通用菜单权限 |
| 6 | 中台管理员页面 | 按 `02-页面权限配置/02-站内信模板逐项复制.md` 配四个模板 | 编码唯一、状态开启、正文参数原样保留 |
| 7 | 中台用户管理 | 管理员创建业务专用账号，仅分配 `cost_role_allocator`；准备普通业务账号 | 不给专员管理员或其他业务角色 |
| 8 | 专员账号 | 登录 → 选择成本树平台 → 精简角色分配页 → 数据授权页，配领域/项目/单位范围 | 每个普通用户只分一种成本业务角色 |
| 9 | 普通用户 | 退出重新登录，验证授权内可见、范围外拒绝；预警推送→反馈→闭环 | 六种身份验权通过后恢复调度 |

管理员仍使用原中台用户管理、角色管理和成本数据授权页；精简分配页只给授权专员。专员角色标识为 `cost_role_allocator`，**不需要新增菜单页或勾选通用用户/角色管理权限**，入口由成本门户按角色提供。

## 重要边界

- 成本库已完整升级过：合并脚本按版本跳过旧升级；仍执行检查、幂等索引修补及验收。缺列或重复键检查失败就停止，不手动删除业务数据。
- 任一 SQL 出现第一条 ERROR：停止，执行 `ROLLBACK;`，保留首条错误。不要继续执行其他备用脚本，不补跑10—16链。
- 页面保存权限通常会触发中台的缓存失效；账号退出重登。主流程不需要手工清 Redis。若之前已直接执行 DM SQL或平台缓存有定制，再走备用精确缓存排错；禁止清空整个 Redis。
- 不执行 `0907首次导入` 中的 DM 初始化 SQL。该目录是 DBA 专用备用流程，不和页面配置混用。
- 每日帕科任务：维持“只清六张中间表 → 源全量装载 → 前检 → 业务 UPDATE＋INSERT → 重算 → 验收”。不清业务库，不覆盖填报、授权、预警处置历史；已有映射正常则无需重配。
- 3D不需要SQL、Node.js或外网资源；前端整个替换，不能只拷几个JS。

## 六种身份自验

管理员：原页面仍可管理；专员：只能角色分配和范围授权，不能给自己或管理员授权；全局查看：全成本范围；科研部：单领域；项目办：授权项目；研制单位：项目×单位交集。项目办推送给有效研制单位账号，单位填写说明，项目办闭环。测试未授权项目直接链接应被拒绝。

无需开发人员日常介入。初次四类角色按钮/模板初始化和专员账号交接仍由中台管理员完成，专员只负责之后的角色及数据范围授权。
