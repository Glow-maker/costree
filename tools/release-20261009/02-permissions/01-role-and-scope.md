# 管理员和成本授权专员操作

管理员在原中台页面检查 `cost_role_allocator`（成本授权专员）角色并分给指定专员；平台用户创建、停用及管理员身份仍由原中台管理。不要给专员分配系统用户 / 角色 / 菜单管理权限，不直接执行 DM SQL。管理员原管理页面保留。

专员进入成本角色分配，能查询当前租户全部账号，包括尚未分配成本角色的用户。选择普通账号后分配一种成本业务角色，再配置范围。管理员、专员和自身授权不能由该专员修改。

| 角色 | 配置范围 |
|---|---|
| 全局查看 cost_global_viewer | 无需范围；可查看导出，不能填报或处置 |
| 科研部 cost_research_department | 单个领域 |
| 项目办 cost_project_office | 一个或多个项目 |
| 研制单位 cost_unit_user | **只选择管理单位，无需选择型号或项目**；项目由有效管理单位参与关系自动关联，金额 / 填报仍限制在授权单位 |

研制单位的选项来自成本单位字典中的有效管理单位。业务填报页面仍需选择项目定位工作令，这是操作筛选，不是额外的项目授权。

成本本地接管后使用固定的成本角色能力，不修改其他中台角色或菜单缓存。无本地角色记录的老账号继续兼容原平台角色；不要批量取消既有角色。撤销本地角色保留撤销记录，不能删除记录让旧角色重新生效。

更改角色会清除旧范围，需要重新配置。范围页面加载时读取 scopeRevision，保存必须回传；角色或范围更新后旧页面保存会提示刷新。出现冲突后重新选择用户，不能反复提交旧页面覆盖他人修改。

六类身份复验：admin 原页面可用；专员显示正确身份、当前租户全用户列表但不能查业务金额；全局查看不可写；科研部只见指定领域；项目办只见授权项目；研制单位只见关联项目中的授权单位数据。
