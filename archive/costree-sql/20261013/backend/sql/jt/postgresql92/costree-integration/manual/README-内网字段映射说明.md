# 分表同步字段映射

适用环境：PostgreSQL 9.2.4 / GaussDB(DWS) 8.2.1。按目标表配置字段映射并执行同步。

## 配置与执行

- 默认读取 `cost_integration` 暂存表。直连业务源表时，仅替换 SQL 顶部 `【现场只修改本段】` 中的 `SELECT`；输出列名、类型和含义保持不变，保留后续校验、更新和插入逻辑。
- 依次执行 `00` 至 `08`，每步异常计数须为 0。首次选两个真实项目验证，再扩大到全量；同一批数据重跑后，记录数和金额不得增加。
- 报错后停止下游步骤，单独执行 `ROLLBACK;`，修正字段映射并完整重跑当前脚本。
- 同一时间仅运行一个正式同步批次。禁止清空或修改 `ads_lc_lshsxm2022`、工作令字典、DWS 凭证明细等源业务表。

调度与审计要求见 [定时任务执行顺序](09-定时任务执行顺序.md)。

## 来源与业务键

| 顺序 | 来源 | 成本库目标 | 关键业务键 |
|---|---|---|---|
| 1 | 主业项目树 | `cost_model_node` | 租户 + 节点编码 |
| 2 | 主业项目 | `cost_project` | 租户 + 主业项目编号 |
| 3 | 权威单位字典 | `cost_unit_dict` | 租户 + 核算单位源 ID |
| 4 | 预分预控项目单位金额 | `cost_unit_cost_detail` | 租户 + 项目编号 + 实际核算单位 |
| 5 | 工作令字典 | `cost_work_order` | 租户 + 项目 + 实际核算单位 + 工作令编号 |
| 6 | 凭证账面明细 | `cost_work_order_ledger_detail` | 租户 + 源明细 ID |

## 字段含义

- `cost_model_node.node_code`：成本库展示树的稳定节点编码。
- `cost_project.project_code`：跨主业项目树、预分预控、工作令和账面的统一业务项目编号。
- `unit_name/accounting_unit_name`：实际核算单位名称。
- `manage_unit_name`：电子所、院部等管理单位简称，只用于树页面聚合，不能代替实际核算单位。
- `amount`：账面原始金额，单位为元。
- `amount_wan`：`amount / 10000`，单位为万元。

## 保留填报内容

- `cost_unit_cost_detail.target_cost_amount`、`approved_amount`：项目办逐单位填写。
- 工作令合同、到款、目标、审定、阶段、分系统、产品简称、配套数和纵向分工：研制单位填写。
- `cost_project` 已有的项目办填报状态、研制单位填报状态和审核状态。
- `cost_warning_record`：由系统业务口径生成，不从源系统导入。

## 脚本映射

| 文件 | 源字段 | 同步逻辑 |
|---|---|---|
| `01` | 节点编码、名称、父节点、层级、领域 | 更新/新增节点并回填 `parent_id` |
| `02` | 主业项目编号、名称、对应型号节点 | 生成项目锚点并保留填报审核状态 |
| `03` | 实际单位 ID/编码/名称、管理单位简称 | 生成单位字典及管理分类 |
| `04` | 项目、实际单位、合同、到款、源更新时间 | 只同步合同和到款，保护目标和审定 |
| `05` | 工作令源主键、项目、实际单位、编号、名称 | 一条逻辑工作令一行，保护研制单位填报 |
| `06` | 明细主键、年度、凭证、单位、项目、工作令、科目、借贷、元金额 | 明细幂等更新/新增并保留借贷 |
| `07` | 无字段映射 | 回填关联并按全部年度借方重算工作令账面 |
| `08` | 无字段映射 | 检查重复、孤立、单位换算、快照和八项组成 |

## 禁止的旧写法

- `DELETE creator='tree'` 后整表重插。
- 将 `manage_unit_name` 写入工作令或单位金额的 `unit_name`。
- 从工作令填报金额汇总生成 `cost_unit_cost_detail`。
- 用项目 + 工作令编号直接关联账面。
- 用查询行号或拼接字段代替真实 `source_detail_id`。

## 映射检查

### 主业项目树

- 一个节点编码只能对应一条记录。
- 非领域节点必须能找到父节点。
- 型号节点须提供业务主业项目编号，不能用节点编码代替。

### 单位

- 源单位编码必须按字符串处理，保留前导零。
- 核算单位名称必须与预分预控、工作令、账面使用同一口径。
- 同一管理单位可以包含多个核算单位。

### 工作令

- `source_work_order_id` 使用工作令字典原表稳定主键。
- 同一工作令跨年度只生成一条业务记录。
- 年度只保存在账面明细。

### 账面

- `source_detail_id` 使用原表真实行主键，不能使用查询结果行号。
- 借、贷都导入，只有借方参与成本统计。
- 优先按源工作令主键关联，避免同编号工作令匹配到多个单位。
