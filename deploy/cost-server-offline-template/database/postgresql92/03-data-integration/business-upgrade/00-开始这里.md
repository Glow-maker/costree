# 20260819 填报保护与分系统字典升级

本目录仅供已有 PostgreSQL 9.2.4 / GaussDB(DWS) 成本业务库补齐 `20260819` 结构。平台达梦库不执行这两个 SQL。

## 执行顺序

1. 停止 `cost-server` 和成本同步任务，完成整库备份。
2. 确认已执行到 `20260818` 科研部领域授权升级。
3. 执行 `01-升级填报保护与分系统字典-20260819.sql`。
4. 保存脚本末尾输出的 `vertical_division=false` 工作令审计清单，由业务人员确认真实横向记录。升级脚本不批量改为 `NULL`。
5. 执行 `02-检查填报保护与分系统字典-20260819.sql`，所有错误计数必须为 0，结构版本必须为 `20260819`。

## 升级内容

- 幂等补齐项目办填报字段。
- `cost_project_basic.stage_code` 扩展为 `varchar(255)`，用逗号保存多选阶段。
- 建立成本库专用 `cost_subsystem_dict`，并从现有项目基本信息和工作令分系统字符串去重回填。
- 移除新建工作令 `vertical_division=false` 的数据库默认值；历史 `false` 不自动修改。

## 边界

- 分系统字典属于成本模块，不依赖或修改 DM8 中台通用字典。
- 本目录不同步外部源数据，也不清空任何业务表。常规同步继续使用 `../snapshot-upsert/`。
- 数据库升级、后端 JAR 和前端资源必须来自同一版本。
