# 达梦 MQB 首次权限导入（20260820）

本目录只在中台平台库的 `MQB` schema 执行，不能在成本 PostgreSQL/GaussDB 业务库执行。

## 执行前

1. 备份 `SYSTEM_MENU`、`SYSTEM_ROLE`、`SYSTEM_ROLE_MENU`、`SYSTEM_USERS`、`SYSTEM_USER_ROLE`、`SYSTEM_NOTIFY_TEMPLATE`。
2. 确认脚本租户编号 `124` 与内网账号所属租户一致；不一致时先统一替换并复核。
3. 使用禁用自动提交、支持失败回滚的 DM8 客户端，串行执行，不要并发运行。

## 固定顺序

1. `01-costree-role-menu-full-20260820.sql`
2. `02-cost-warning-notify-template-20260820.sql`
3. `03-check-cost-permissions-20260820.sql`

这是当前完整初始化，不需要先执行历史权限脚本。第一步创建或校正四类成本角色、19 个权限点和 34 条角色权限映射；第二步创建四类预警站内信模板；第三步所有状态必须为 `OK`，缺失和意外映射计数必须为 0。

脚本不会创建用户、修改密码或给用户分配角色。用户和角色关系仍在业务中台系统用户页面维护；领域、项目和管理单位范围在成本数据授权页维护。

## 执行后

平台 SQL 不会触发 Spring Cache 自动失效。按部署手册精确删除当前租户相关的 `role`、`menu_role_ids`、`permission_menu_ids`、`notify_template` 缓存键，再让测试账号退出并重新登录。禁止执行 `FLUSHDB` 或 `FLUSHALL`。
