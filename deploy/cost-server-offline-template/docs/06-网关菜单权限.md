# 网关、菜单和权限

## 网关

现有网关应注册以下路由：

```text
/admin-api/cost/** -> grayLb://cost-server
```

在 Nacos 中确认服务名严格为 `cost-server`。如果直接访问服务正常、经网关 404，优先检查路由和服务注册，不要修改前端接口地址。

## 权限

在平台库执行 `database/platform/check-cost-permissions.sql`，结果只应出现 `OK`。缺失权限请在平台“菜单管理”中建立按钮权限，再由“角色管理”授权，避免在不了解内网菜单 ID 的情况下硬编码 INSERT。

最低只读演示权限：

- `cost:project:query`
- `cost:project-basic:query`
- `cost:work-order:query`
- `cost:warning:query`

门户增加只读“工作令查询”入口 `/cost/work-order-list`，复用
`cost:work-order:query`。项目办按单位保存目标、审定需要
`cost:project-basic:update`。

填报和管理还需对应的 create/update/delete/import/export 权限。账面明细与工作令成本导出允许具备工作令查询或导出权限的用户使用；如果按钮不可见但接口存在，先检查角色权限和前后端是否来自同一版本。

## 租户

前端请求会携带 `tenant-id`。数据同步脚本中的租户 ID 必须与登录账号所属租户一致，否则数据库有数据但页面查询为空。
