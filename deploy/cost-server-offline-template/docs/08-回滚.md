# 回滚

## 应用回滚

1. 停止当前 `cost-server`。
2. 恢复上线前 JAR 和外置配置。
3. 恢复前端备份目录并重载 Nginx。
4. 启动旧服务并完成基本接口验证。

## 数据库回滚

数据库升级会合并逻辑工作令、补业务防重索引并重建借方账面快照，不提供反向 SQL。需要回滚时恢复上线前数据库备份，这是唯一可靠路径。

## 数据同步批次回退

正式同步采用 UPSERT，可能更新既有记录。不要直接按 `creator` 大范围删除。应根据同步前备份、`cost_import_batch` 批次和源业务键生成经审核的定向回退脚本。

演示数据清理脚本只允许用于本包明确标记的专用演示项目，禁止在真实库执行。
