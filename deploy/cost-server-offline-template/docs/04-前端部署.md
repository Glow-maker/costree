# 前端部署

本包 `frontend/dist` 是完整管理端构建产物，不是单独的成本模块碎片。Vite 文件名带内容哈希，必须整体发布。

## Windows 站点

```powershell
.\frontend\deploy-frontend.ps1 -WebRoot 'D:\nginx\html'
```

脚本会先压缩备份旧目录，再替换完整静态资源。执行前确认 `WebRoot` 是现有管理端站点根目录。

## Linux 站点

推荐发布到版本目录后切换软链接：

```bash
release=/opt/releases/costree-$(date +%Y%m%d%H%M%S)
mkdir -p "$release"
cp -a frontend/dist/. "$release/"
ln -sfn "$release" /opt/costree-frontend
nginx -t && systemctl reload nginx
```

Nginx 示例位于 `frontend/nginx/costree-admin.conf.example`。前端使用同源 `/admin-api`，该路径应代理到现有网关，不直接代理到 `cost-server`。

## 验证

- 打开登录页并使用真实平台账号登录，不能出现本地模拟登录。
- 浏览器 Network 中成本接口路径以 `/admin-api/cost/` 开头。
- `/cost/catalog` 首屏项目接口使用分页参数，不应携带超长 `projectCodes`。
- 强制刷新浏览器后检查首页、目录、成本树、项目详情、数据采集和账面组成导出。
