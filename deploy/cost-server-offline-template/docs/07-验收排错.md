# 验收与排错

## 上线验收

1. `tools/verify-package` 校验通过。
2. 数据库 `20-verify.sql` 所有错误计数为 0。
3. Nacos 中 `cost-server` 健康，网关可转发成本接口。
4. `/cost/catalog` 服务端分页和全库搜索正常。
5. 首页合同、到款等于预分预控项目单位汇总；目标、审定等于项目办逐单位填报汇总。
6. 工作令账面等于全部年度借方明细合计，贷方不计入。
7. 八项组成合计等于借方账面，可穿透并导出。
8. 同一导入批次执行两次，记录数和金额不增加。
9. 项目办保存目标、审定后再次同步预分预控，目标、审定不被覆盖。
10. `/cost/work-order-list` 可按项目、单位、编号、阶段分页查询。

## 常见问题

### `column ... does not exist`

后端版本新于数据库。执行本包的完整旧库升级，不要只补当前报错列，否则下一接口仍会继续报缺列。

### PostgreSQL 9.2 报 `syntax error at or near CONFLICT/IF`

执行了 PostgreSQL 14+ 脚本。先 `ROLLBACK;`，确认 `SHOW server_version_num;` 返回 `902xx`，然后改用 `database/postgresql92` 中同名步骤。两套脚本不能交叉执行。

### DWS 报唯一索引必须包含分布键

执行了旧版或原生 PostgreSQL 脚本。当前 `postgresql92` 脚本在 DWS 会创建同名普通防重索引，不应出现该错误。先 `ROLLBACK;`，确认包中存在 `00-dws-precheck.sql`，重新运行本包的一键升级脚本。不要手工追加不含分布键的唯一索引。

### `current transaction is aborted`

同一事务前面已有真正错误。先回滚，再查第一条 `ERROR`。后面的这句话不是根因。

### DWS 同步出现重复业务键

确认没有两个工作流并发执行 `10-sync-to-cost.sql`，也没有任务直接写 `cost_*` 业务表。停止写入后运行 `20-verify.sql`，先清理报告出的重复键，再从暂存层完整重跑。

### HTTP 414 Request-URI Too Long

旧前端曾把大量项目编码放进 GET URL。当前目录页应使用 `/cost/project/page?pageNo=...&pageSize=...`。出现 414 通常是前端未整体替换或浏览器缓存仍是旧资源。

### 导出按钮看不到或返回 403

检查前端是否为本包版本，并检查 `cost:work-order:query` / `cost:work-order:export` 权限。再确认网关没有缓存旧实例。

### 金额大 10000 倍或小 10000 倍

账面源 `je` 为元；写入 `amount_wan` 时只除一次 10000。页面直接显示万元字段，不能再次换算。

### 页面有项目但没有单位或工作令

依次核对项目编码、租户 ID、核算单位名称、工作令编号。管理单位简称只用于汇总展示，账面关联必须使用实际核算单位。

### 院内账面成本全部为 0

页面读取的是 `cost_work_order.book_cost_amount` 工作令借方快照，不读取单位成本表中的历史 `book_cost_amount`。先执行对应数据库目录下的 `03-data-integration/30-diagnose-book-zero.sql`：

- `ledger_all > 0` 但 `ledger_debit = 0`：源字段 `jzfx` 不是精确的“借”，先治理借贷方向。
- `missing_work_order_id_count > 0`：账面明细没有关联工作令，优先核对 `gzlnm` 是否等于工作令源表 `id`。
- 借方明细有金额但脚本第 5 组返回记录：工作令快照未重建，修正暂存数据后重新执行 `10-sync-to-cost.sql`。
- 只有 `unit_cost_legacy_book` 有金额：这是旧兼容字段，不能作为当前账面来源，必须导入工作令账面明细。

不要直接手工把单位账面复制到工作令。修正源关联后重新同步，脚本会按全部年度借方明细重建快照。

### 后端启动时 MyBatis XML SAX 错误

检查 JAR 是否来自本包并通过 SHA256 校验。不要混用旧 target 目录或手工替换 mapper XML；重新部署完整 JAR。

### 饼图无数据

检查账面明细是否为借方、科目编码是否落在 `501101-501108`、项目/单位/工作令关联是否解析成功。
